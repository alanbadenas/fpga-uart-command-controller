# FPGA UART Command Controller

Academic Master's coursework project containing a Cyclone 10 LP / VHDL prototype with UART transmit/receive logic, command control, ACK handling, error-buffer experiments, and a serial host-side test script.

> **Academic project.** This repository is not presented as commercial experience.

The first public snapshot intentionally excludes the original virtual environment, Quartus build databases, generated IP trees, simulation caches, and other machine-generated artifacts. A subsequent commit streamlines the source tree and documentation for portfolio use.
